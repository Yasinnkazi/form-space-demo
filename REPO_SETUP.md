# Form + Space — Repository Setup

## Recommended Repository Name

**form-space-demo**

## GitHub Setup

```bash
git remote add origin https://github.com/YOUR_USERNAME/form-space-demo.git
git branch -M main
git push -u origin main
```

## Vercel Deployment

```bash
npm i -g vercel
vercel --prod
```

Or connect your GitHub repo directly in the Vercel dashboard.

## Recommended Domain

- `formandspace.design` or `form-space-demo.vercel.app`
